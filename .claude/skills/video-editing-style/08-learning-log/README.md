# 08-learning-log: what was learned, and when

| File | What it holds |
|---|---|
| `08-learning-log/CHANGELOG.md` | everything learned, by date, newest first |
| `08-learning-log/VIDEO-25-POSTMORTEM.md` | what fell short in the rejected video 25 and what a pro edit would have built, line by line |
| `02-craft/shorts-editing-pro/LEARNING-LOG.md` | every short (videos 16-25) and every piece of feedback; it stays beside `shortkit.py` because the workflow appends to it |
| `04-styles/pro-video-editing/knowledge/CHANGELOG.md` | changelog of the reference library |

## Routine
- After every edit: append to `02-craft/shorts-editing-pro/LEARNING-LOG.md`.
- After every lesson or piece of feedback: save it with `06-tools/skill-saver/GUIDE.md` and add a dated CHANGELOG entry (the owner's words in quotes, what was saved where, what is still open).
- After any skill is added, renamed or moved: `python3 06-tools/tools/build_index.py`.

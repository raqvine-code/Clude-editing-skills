# 07-edit-kit-reference: the Edit-Kit, text only

41 open-source video skills (HyperFrames family; MIT and Apache licences in `licenses/`), stored here unmodified except that code, media and assets were left out. Only the text (`SKILL.md`, guides, references, licences) is kept.

Do not read this folder directly. `02-craft/edit-kit-playbook/SKILL.md` is the distilled layer: it routes a job to the one kit skill worth opening, and holds the speech-to-visual map, beat grammar, caption model and motion seam law.

Most kit skills generate a video from code (anime, pixel art, shaders, three.js, storybook, whiteboard). They are a different pipeline from editing footage in After Effects. The owner's rules rank above the kit; the kit's installers were never run.

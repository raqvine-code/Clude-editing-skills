- **Colour rules learned:**
  - Dark worlds stay near-neutral or one hue; semantic colours (green good → red bad) belong inside the data object only, never in the world.
  - One warm or off-hue object in a monochrome scene is enough accent (a bulb, a coin stack).
  - A glow on white type is what lets thin text read on a luma-20 field.
  - Hue is never copied: ref68's violet is the disliked palette, and ref67's red was already the red-glass look (refs 41–49). Reuse the structure in the video's own accent.
  - **Neutral page + one saturated action colour (ref69):** an untinted `#F7F7F7` page with one pure-saturation blue for the button reads as "product UI"; the same hero gradient is reused for the opening logo and the CTA so the video bookends in one colour.
- **Stand-ins from Deepak's list for these roles:**
  - Condensed hero caps: **Impact** (installed), or Heading Now (not installed; use the Archivo narrow stand-in from the table, or Anton / Bebas Neue when it must be heavier).
  - Labels and axes: **Inter** (regular/medium; not installed on this Mac, free download). Keep ≥ 24 px at 1080p (`mistakes-to-avoid` C7), which the references break.
  - Tight light → bold grotesk lines: Inter or Tactic Sans (normal width) with tracking −2…−4 %.
  - Hero numerals in a gradient: Tactic Sans Extended or Archivo Black.

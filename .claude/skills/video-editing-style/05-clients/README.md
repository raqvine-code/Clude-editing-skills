# 05-clients: rules that belong to one client

Why this folder exists: the skills were first written while editing for Tech Boy Deepak and Naveen bro, so their taste (fonts, caption colours, "no tilted cards", "no BGM") was written as if it were law for every video. It is not. Client taste lives here; craft lives in `02-craft/`; styles live in `04-styles/`.

## How to load a client (step 1 of every edit)
1. Open `05-clients/<client>/` and read its README or PROFILE (and any client skill listed there).
2. Those rules beat the style skill for that client only. The owner's latest word beats both.
3. No folder for this client? Copy `_TEMPLATE.md` to `05-clients/<new-client>/PROFILE.md`, ask the questions in it once, then run to the end.
4. Never put one client's branding, fonts or palette on another client's video.

## What counts as client taste vs craft
- Client taste: palette, font pairing, caption colours, whether music or a grade is allowed, what the client dislikes, delivery folder.
- Craft (applies to every client): the floors in `01-process/before-edit/2-PRO-MOVE-MENU.md`, the event map, the speech-to-visual map, sound grammar, safe zones, QC.
- Mixed skills carry a `Scope:` line under their frontmatter saying which parts are which.

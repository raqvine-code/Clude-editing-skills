# CLAUDE EDITING BRAIN: start here

A rulebook for editing video like a senior editor and motion designer. It was written from 25 delivered edits, 100+ reference videos and reels, and client feedback (October to 26 November 2026), then reorganized on 26 November 2026 into layers so any rule is one hop away. Since 27 November 2026 this folder is also the Claude skill `video-editing-style`: `SKILL.md` at its root is the entry point, and every skill file inside the layers is named `GUIDE.md`.

Owner: Raghu (studio: RAQVINE; channel: Move with Raghu). Skills were first written for the clients Tech Boy Deepak and Naveen bro; their taste is now kept apart in `05-clients/`.

## 60-second start
1. Read `CLAUDE.md` (the master rules, one page).
2. Load the client: `05-clients/README.md` says how.
3. Read the Core 5 (below), then only the rows of the router that match the job.
4. Pass the gate before any full render: `01-process/before-edit/README.md`.

## Known limits (read before trusting a style)
- P12-P15 were learned from analysis packs without a test render; P15's brief never arrived. Treat them as ideas.
- P16 and the M4 captions had not been seen by the client when this was written; video 25 was rejected before its rebuild.
- Nothing here is measured for challenge or comedy pacing (the Move with Raghu format). See `05-clients/move-with-raghu/PROFILE.md`.
- P17-P20 come from four short editor adverts (11-32 s), picture measured, sound inferred; no client has seen an edit built with them yet.
- Clips, PNGs, reference videos, finished videos and most fonts are not in this zip; see `PATHS-AND-SETUP.md`.

# Style analysis: the evidence (V1)

This file covers reference video 1 only. Video 2 ("14 Brutally Honest Truths", studied 2026-11-20 with full shot, text, framing and audio measurement) is in `video2-14-truths.md`.

## What was studied
- Video: 600 s, 3840x1920 (2:1), 25 fps, speaker in olive polo at desk, long-form educational list video.
- Method: cut detection (ffmpeg scene > 0.25, 234 raw / 208 merged cuts), 1 frame/5 s contact sheets over all 600 s, 8 fps frame strips around key moments (2:28-2:32 "10/10" headline, 5:00-5:04 ad scene, 7:46-7:53 "HUMBLE FLEX"), 20 user screenshots, faster-whisper transcript, EBU R128 loudness.

| Item | Value |

| Frame | 3840x1920; graphics use letterbox-free full frame; some B&W clips are shrunk inside black |

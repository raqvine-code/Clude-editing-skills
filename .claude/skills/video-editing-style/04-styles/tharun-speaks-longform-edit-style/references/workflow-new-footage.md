# Applying the style to new footage

## Inputs
Talking-head footage (16:9 or 2:1), script/transcript, any real photos/screens the topic needs.

## Steps
1. **Transcribe** (faster-whisper) and mark: tip titles, nouns that can be drawn, jokes/quotes, ad read.
2. **Assembly cut**: remove pauses, keep natural breath; aim for a cut every 2-4 s using jump cuts and 100%/120% scale alternation.
3. **Chalkboard template**: dark charcoal texture + grain + vignette in the NLE/After Effects; set the 4 type roles.
4. **Storyboard table**: columns time | line | visual | type role. One visual per noun or example; max 8 s without the speaker.
5. **Build graphics** from the catalogue (`motion-graphics.md`). Reuse a master brain with 9 nodes; animate the dot.
6. **Headlines**: pick 8-15 punch words; roto/matte the speaker, put white condensed text behind.
7. **Captions**: only in fast sections; 1-3 words, size-step on the key word.
8. **Sound**: bed, whooshes, ducking; loudness target above.
9. **Grade**: warm A-roll, desaturate B&W beats.
10. **Render a 60 s sample**; compare against checklist; then full render.

## Checklist
- [ ] Median shot ~2-3 s; no 20 s without a visual change.
- [ ] Every graphic enters in <= 12 f and leaves with the idea.
- [ ] Red used only for negatives.
- [ ] Headlines pop in 1 frame, behind the head.
- [ ] Captions on key nouns only, lower-centre.
- [ ] Chalkboard scenes share grain/vignette values.
- [ ] No reference-creator branding.
- [ ] Loudness within -12..-10 LUFS, peak <= -1 dBTP.

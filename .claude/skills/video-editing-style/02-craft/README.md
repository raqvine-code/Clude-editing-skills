# 02-craft: how to build any edit

Craft applies to every client. Client taste is in `05-clients/`; looks are in `04-styles/`.

| Group | Skills |
|---|---|
| Method for every short | `shorts-editing-pro/` (playbook, `tools/shortkit.py` renderer, `LEARNING-LOG.md`), `event-map-reel-edit-style/` (event map, 1.3 s rule, sync table, sound grammar; also P13 and P14), `reel-editing-method/` |
| The always-read layer | `edit-kit-playbook/` (router to the kit, speech-to-visual map, caption model, motion seam law), `beginner-to-pro-edit-tips/`, `my-editing-rules/` (mixed: sections 6-11 are general) |
| Motion graphics and text | `motion-graphics-style/` (learned from 82 references), `text-animation-moves/`, `text-highlight-match-cut/` (HL and MC), `video-intro-design/`, `app-product-animation/` |
| Long-form and special jobs | `youtube-long-video-editing/` (16:9 build kit), `client-video-editing-process/` ("boring video to high engagement", camera keyframes, number reveals), `motivational-video-editing/` |

Start from the Core 5 in `README.md`. `INDEX.md` has the use-when line for each skill.

`shortkit.py` needs ffmpeg (env `FF` overrides the search) and fonts (env `EDIT_FONTS` overrides the folder). See `PATHS-AND-SETUP.md`.

Colour lessons:
- Dark worlds stay near-neutral or one hue; semantic colours (green good to red bad) belong inside the data object only.
- One warm/off-hue object in a monochrome scene is enough accent.
- A glow on white type lets thin text read on a luma-20 field.
- Never copy hue (68's violet is disliked; 67's red = earlier red-glass look): reuse structure in the video's own accent.
- Neutral page + one saturated action colour reads as product UI; reuse the same hero gradient for opening logo and CTA to bookend.

Stand-ins for reference roles: condensed hero caps = Impact (or Archivo narrow, Anton/Bebas Neue when heavier); labels/axes = Inter regular/medium, >= 24 px at 1080p; tight light-to-bold lines = Inter or Tactic Sans normal width, tracking -2..-4 %; hero gradient numerals = Tactic Sans Extended or Archivo Black.

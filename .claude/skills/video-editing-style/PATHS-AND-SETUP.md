## Running the tools
| Job | Command |
|---|---|
| Analyse raw footage | `python3 04-styles/pro-video-editing/tools/analyze_raw.py <video> <project_dir>` |
| Gate (draft EDL, then again before delivery) | `python3 01-process/before-edit/tools/pre_edit_gate.py <project>/edl.json [--facts <project>/analysis/facts.json]` |
| Render a short | `02-craft/shorts-editing-pro/tools/shortkit.py` (read its Files section in `02-craft/shorts-editing-pro/GUIDE.md`) |
| Rebuild INDEX.md and check structure | `python3 06-tools/tools/build_index.py` |
| Render caption / card moves (P17-P20) as `layers` | `python3 04-styles/editor-showcase-caption-edit-style/tools/caption_moves.py <spec.json> <project>/assets/moves --sheet` |
| Learn a style from a video file | `06-tools/watch/scripts/watch_mac.py` (see `06-tools/watch/GUIDE.md`) |

Environment variables: `FF` or `FFMPEG` = path to ffmpeg (otherwise PATH, Homebrew, then imageio-ffmpeg); `EDIT_FONTS` = font folder for `shortkit.py` (default `03-sound-type-assets/fonts-and-colours/assets/fonts`, which holds only 6 files, so point it at the full library for other fonts).

Python packages the tools import: numpy, scipy, opencv (`cv2`), Pillow (with raqm for Telugu), imageio-ffmpeg, mediapipe, and faster-whisper (the scripts expect it in `~/.local/share/whisper-venv`). `06-tools/MAC-TOOLCHAIN.md` says what was installed on the Mac on 2026-11-25 and how.
